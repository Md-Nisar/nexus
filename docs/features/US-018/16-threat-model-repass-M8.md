# US-018 M8: threat-model re-pass (preparation)

Status: prepared by the implementer; the Security sign-off is pending. Integration tests named below were written and compile but **were not run** (no Docker). "Unit" means the test ran green in `verify -DskipITs` (2042 run, 0 failures, 2 skipped: one pre-existing, one `@Disabled` RC-54(b) test). Paths: backend `nexus-backend/src/main/java/com/example/nexus/`, tests `nexus-backend/src/test/java/com/example/nexus/`. RAS = `rbac/application/RoleAssignmentService`, RMS = `rbac/application/RoleManagementService`.

## 2. Line a human must add to `application-prod.yml`

Under the existing `nexus.rbac` block (next to `redis.require-auth: true`):

```yaml
nexus:
  rbac:
    throttle:
      require-shared-store: true
```

and set `nexus.security.rate-limit.store-type: redis` for production (file or `NEXUS_SECURITY_RATE_LIMIT_STORE_TYPE=redis`). Then remove the `@Disabled` on `should_resolveRequireSharedStoreTrue_when_prodProfileActive`.

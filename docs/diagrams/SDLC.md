
The Software Development Life Cycle (SDLC) is a structured process for planning, developing, testing, deploying, and maintaining software. While organizations may customize it, a typical SDLC consists of the following stages:


| Stage                                    | Purpose                   | Key Activities                                                                         | Deliverables                                                |
| ---------------------------------------- | ------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **1. Requirements Gathering & Analysis** | Understand business needs | Meet stakeholders, gather functional/non-functional requirements, feasibility analysis | SRS (Software Requirements Specification), user stories     |
| **2. Planning**                          | Define project roadmap    | Scope, timeline, budget, risk assessment, resource planning                            | Project plan, milestones, risk register                     |
| **3. System Design**                     | Design the solution       | Architecture design, database design, API design, UI/UX design, security planning      | HLD (High-Level Design), LLD (Low-Level Design), wireframes |
| **4. Development (Implementation)**      | Build the application     | Coding, unit testing, code reviews, documentation                                      | Source code, unit tests                                     |
| **5. Testing (Quality Assurance)**       | Verify quality            | Functional, integration, regression, performance, security, UAT                        | Test cases, defect reports, test reports                    |
| **6. Deployment (Release)**              | Release to users          | CI/CD, environment setup, database migration, production deployment                    | Production release                                          |
| **7. Maintenance & Support**             | Keep software operational | Bug fixes, monitoring, enhancements, security patches                                  | Updated releases, support documentation                     |

Maven lifecycle phases, commands, and their purpose

Phase Command Lifecycle Purpose
Clean
pre-clean mvn pre-clean clean Executes processes needed before the actual project cleaning
clean mvn clean clean Removes the target/ directory and all generated build outputs
post-clean mvn post-clean clean Executes processes needed to finalise the project cleaning
Default
validate mvn validate default Validates that the project is correct and all necessary information is available
initialize mvn initialize default Initialises build state — sets properties, creates directories
generate-sources mvn generate-sources default Generates source code (e.g. from WSDL, Thrift, or annotation processors)
process-sources mvn process-sources default Processes the source code, e.g. filtering or replacing tokens
compile mvn compile default Compiles the project's main source code into target/classes
process-classes mvn process-classes default Post-processes compiled classes — bytecode enhancement or instrumentation
generate-test-sources mvn generate-test-sources default Generates test source code to include in compilation
test-compile mvn test-compile default Compiles test source code into target/test-classes
test mvn test default Runs unit tests using a framework such as JUnit or TestNG — does not package
prepare-package mvn prepare-package default Performs pre-packaging operations — unpacking, merging, or modifying resources
package mvn package default Packages compiled code into a distributable format — JAR, WAR, EAR
pre-integration-test mvn pre-integration-test default Sets up the environment for integration tests — starts servers or databases
integration-test mvn integration-test default Deploys the package and runs integration tests against it
post-integration-test mvn post-integration-test default Tears down the integration test environment — stops servers
verify mvn verify default Runs checks to confirm the package is valid and meets quality criteria
install mvn install default Installs the package into the local repository for use as a dependency by other projects
deploy mvn deploy default Copies the final package to the remote repository for sharing with other teams or CI environments
Site
pre-site mvn pre-site site Executes processes needed before site generation
site mvn site site Generates the project's documentation site — Javadoc, reports, test results
post-site mvn post-site site Executes processes needed to finalise site generation and prepare for deployment
site-deploy mvn site-deploy site Deploys the generated site to a web server — typically via SCP or FTP
